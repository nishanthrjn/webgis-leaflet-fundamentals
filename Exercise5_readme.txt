# Exercise 5 – PostGIS / SQL (Internet-GIS)

This folder contains the SQL work for Exercise 5.

The exercise uses the PostGIS database `webgis` hosted at `gis.ikg.uni-hannover.de` and is only reachable from LUH LAN / LUH VPN.

## Tasks covered
- **5.1** Connect to DB using `psql`, list tables (`\dt`).
- **5.2** Inspect schemas and explore attributes (example: `shop`).
- **5.3** Inspect geometry column `way`, export as WKT/EWKT/GeoJSON, transform 3857→4326, bounding box queries.
- **5.4** Optional QGIS exploration (not required for submission).
- **5.5** Only for final exercise participants (see `sql/05_05_topic_queries.sql`).

# WebGIS & Leaflet Fundamentals

Practical WebGIS exercises demonstrating **client-side spatial data handling** and **interactive web maps** using Leaflet.

The repository shows a **progressive WebGIS skill set**: from static map interaction to modern Leaflet-based maps with vector layers, events, and parsed spatial data formats.

---

## What This Repository Demonstrates

- Building interactive web maps with **Leaflet**
- Working with **GeoJSON** and **XML-based geometries**
- Client-side parsing and visualization of spatial data
- Layer styling and feature-level interaction
- Map events (click, zoom, bounds, hover)
- Clean HTML/CSS layout for map-centric applications

---

## Technology Stack

- JavaScript (ES6)
- Leaflet.js
- HTML5 / CSS3
- GeoJSON
- XML parsing
- OpenStreetMap tiles

This repository focuses on **core WebGIS fundamentals** relevant for:
